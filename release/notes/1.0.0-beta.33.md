# Lamphaus 1.0.0-beta.33

Choose whether the next episode starts on its own, and a cleaner source list on TV.

- New Settings → Ask before next episode: when an episode ends, Lamphaus shows what's up next and asks "Continue watching?" with Yes or No instead of starting it automatically.
- The TV source list is easier to scan: each source leads with its quality (4K, 1080p, 720p), add-on filters show how many sources each one found, and long add-on descriptions no longer fill the screen.
- Known limits: with Ask before next episode on, an unanswered prompt closes the player after 60 seconds.
