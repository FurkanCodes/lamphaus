# Lamphaus 1.0.0-beta.2

Improves TV playback display matching for smoother video cadence and source resolution changes.

- Matches supported display refresh rates, including fractional rates and integer cadence multiples.
- Matches source resolution independently when frame-rate metadata is unavailable.
- Restores the previous display policy when playback ends or the source changes.
- Known limits: physical TV and HDMI mode switching still require device-specific verification.
