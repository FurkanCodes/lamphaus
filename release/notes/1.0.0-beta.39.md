# Lamphaus 1.0.0-beta.39

UHD Blu-ray remuxes now play in Dolby Vision on more TVs and boxes.

- Dolby Vision profile 7 remuxes play in Dolby Vision on devices that support profile 8, instead of falling back to HDR10.
- Source lists no longer say "Dolby Vision as HDR10" for those remuxes on devices where they now play in Dolby Vision.
- Known limits: the remux's enhancement layer is set aside; the picture is the HDR10 base layer with Dolby Vision's dynamic metadata.
