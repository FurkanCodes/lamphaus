# Lamphaus 1.0.0-beta.49

Updates now set Lamphaus up to run at full speed as soon as they install.

- In-app updates now install with the app's speed profile, the way Play Store apps do, so Android prepares Lamphaus during the update instead of days later when the device is idle. Starting the app and moving around are faster right after an update.
- Known limits: this takes effect from the update after this one; until then, Android prepares Lamphaus the next time the device sits idle.
