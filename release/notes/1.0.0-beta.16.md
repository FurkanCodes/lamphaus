# Lamphaus 1.0.0-beta.16

Adds a Spotlight Home layout on Android TV and makes remote navigation more predictable.

- New Spotlight layout (Settings → Appearance → Home layout): the selected title widens in its row with its details underneath. Classic stays the default.
- Moving between rows returns to the title you left, and the end of a row no longer jumps to the top menu.
- Discover and Search filters are reachable with the remote again, and Up from the search field returns to the menu.
- "In Library" on a title can be selected again to remove it.
- New Background artwork setting (Settings → Appearance), and Home backgrounds are sharp again at full screen resolution.
- Episode redesign: resume progress, the next episode highlighted, and easier-to-read cards.
- Known limits: Spotlight moves between rows slightly less smoothly than Classic on low-end TVs.
