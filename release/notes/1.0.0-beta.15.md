# Lamphaus 1.0.0-beta.15

Handles large add-on setups better on Android TV: sources appear sooner and long lists stay smooth.

- Sources appear as soon as each add-on answers, in your add-on order, instead of waiting for the slowest one.
- Long source lists scroll smoothly, and the selected source stays in place as more arrive.
- Home loads further ahead when add-ons add many rows; empty rows no longer appear and then vanish.
- The first profile on a new install now finishes setting up reliably.
- Known limits: a very slow add-on still delays the Home rows that come after it.
