# Lamphaus 1.0.0-beta.53

4K remuxes buffer far less, subtitles no longer hold up the stream, and libmpv starts reliably.

- High-bitrate files now download over several connections with a larger memory buffer, so large remuxes keep playing where they used to stop and buffer. You can change both in Settings → Playback → Streaming.
- A stream starts as soon as it is ready: a slow subtitle add-on costs only its own subtitles, and tracks that arrive late wait in the Subtitles panel behind "Add more subtitles".
- libmpv no longer sits on Loading when resuming or when a source needs request headers, which affected anime most, and the loading screen clears as soon as the first frame shows.
- 4K 60 fps video on TV boxes no longer shows a false "cannot decode" message over a picture that is playing fine.
- Cast members on TV details pages can be focused: Select opens their page or searches their name, and Back returns to the same card.
- Coming back from More like this on TV returns to the card you opened it from.
- Catalog rows recover properly: Retry works when a row's first page failed, errors say what happened, and a recovered TV row hands focus to its first card.
- Fixed two crashes on phones in the source list and the episode list.
- Crash reports, for viewers who turn them on in Settings → Privacy, now say which page the crash happened on, so problems on Home and elsewhere can be traced.
- Known limits: the new streaming defaults have not yet been tried on every host, so if a source buffers or stalls, turn off Parallel connections in Settings → Playback → Streaming and tell us. Occasional TV crashes reported on the last beta are not fixed yet; this build is meant to help find their cause.
