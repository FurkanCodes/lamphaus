# Lamphaus 1.0.0-beta.3

Fixes TV update flows that appeared to do nothing after downloading or selecting Install.

- Shows the install-permission screen on TV and resumes when you return from Android Settings.
- Opens Android's installation confirmation and shows recoverable installation errors.
- Keeps paused downloads visible with a cancel action and an optional metered-network download.
- Known limits: beta 1 and beta 2 need one manual APK installation to receive this updater fix. TV flow verified on an Android 16 emulator; physical TV firmware may differ.
