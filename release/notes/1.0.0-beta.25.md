# Lamphaus 1.0.0-beta.25

The next episode starts like any other playback, with the TV's frame rate matched.

- Moving to the next episode, or picking another source in the player, now starts a fresh playback, so frame-rate matching and the start work the same as when you first press Play.
- Known limits: the TV may briefly switch display mode between episodes, as it does when playback first starts.
