# Lamphaus 1.0.0-beta.6

Fixes playback crashes when Android emulators encounter Dolby Vision streams, while retaining the beta 5 startup fix.

- Routes Dolby Vision streams away from unsupported emulator MediaCodec decoders and uses MPV software decoding.
- Keeps real Android TV hardware on its normal Media3 decoder path with MPV fallback for decoder failures.
- Keeps one Continue Watching card per title when several episodes have saved progress.
- Known limits: Dolby Vision software decoding on an emulator can be CPU-intensive; physical phone and TV firmware remain to be tested.
